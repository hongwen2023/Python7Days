# 机器学习 · 深度学习 数学学习路线图

> 4 根支柱:**线性代数 · 多元微积分 · 概率统计 · 最优化**。
> 以鸢尾花书(姜伟生)+ MIT 18.06/18.065 为主干,外部资源补缺。
> 每阶段用一个 **🎯 从零手写** 来验收——能写出来才算真懂。
> 用时按每周 ~8–10 小时估算,总计约 7–9 个月到"能读懂 DL 论文数学"。

---

## 高效学习的 5 条铁律

1. **线代不断线** —— 唯一的关键路径,卡住就全卡住,持续推进。
2. **并行穿插** —— 主攻线代,每周穿插微积分/概率,别串行等。
3. **项目驱动** —— 每阶段一个 NumPy 从零实现,胜过刷十道题。
4. **倒查式** —— 学算法时回查数学,别想学完全部再开始。
5. **狠心跳过** —— DL 用不到的证明/复分析/Jordan,看到就跳。

## 关键路径

```
线性代数 ──┬──► 多元微积分+矩阵求导 ──┐
          │                          ├──► 经典ML ──► 深度学习
概率统计 ──┴──► 最优化 ───────────────┘
```

## 🔴 阶段 1:线性代数(核心)· ~8–10 周

**你正在这里。** 矩阵是 DL 的语言,前向传播就是矩阵乘法。

- [ ] **主线**:MIT 18.06(已到 L10)+《线性代数不难》配套(逐讲见 18.06 清单)
- [ ] 必掌握:矩阵乘法四视角 · 投影/最小二乘 · 特征值分解 · SVD · 正定/二次型
- [ ] 深化(选):《矩阵力量》SVD / 特征值 / 二次型 章
- [ ] 进阶(选):18.06 后接 **MIT 18.065**(Strang 的 ML 线代课)
- [ ] 🎯 手推「最小二乘 = 投影」
- [ ] 🎯 用 NumPy 从零实现 PCA
- [ ] 🎯 能用「旋转-缩放-旋转」解释 SVD
- **可跳过**:复矩阵/FFT、Jordan 标准形、微分方程 e^(At)

## 🔴 阶段 2:微积分 → 多元微积分 → 矩阵求导(核心)· ~4–6 周

**DL 的命门。** 最多人跳过、结果一直懵的地方,务必吃透。

- [ ] 打底:单变量微积分 —《数学要素》导数/积分部分(会了就快速过)
- [ ] 多元:《矩阵力量》Ch17 多元函数微分 —— 偏导 · 梯度 · Jacobian · Hessian
- [ ] 矩阵求导:"The Matrix Calculus You Need for Deep Learning"(Parr & Howard,免费)
- [ ] 直觉:3Blue1Brown《Neural Networks》系列 —— 链式法则讲到极致直观
- [ ] 🎯 亲手推导 + NumPy 实现一个两层网络的 backprop(不用框架)

## 🟠 阶段 3:概率统计(重要)· ~5–6 周

损失函数(交叉熵/极大似然)、softmax、生成模型的来源。

- [ ] 主线:《统计至简》(Book5)
- [ ] 重点:Ch02 描述统计 · Ch04–07 分布 · Ch09–13 高斯家族+协方差矩阵 · Ch16 极大似然 · Ch18–22 贝叶斯
- [ ] 必掌握:期望/方差 · 高斯分布 · 极大似然(MLE)· 贝叶斯 · 交叉熵/KL 散度
- [ ] 🎯 推出「为什么分类用交叉熵损失」(= 极大似然)

## 🟠 阶段 4:最优化(重要)· ~2–3 周

梯度下降怎么把损失降下去 —— 训练神经网络的引擎。

- [ ] 约束:《矩阵力量》Ch18 拉格朗日乘子法
- [ ] 梯度下降:任一 ML 课优化章;凸优化看 Boyd《Convex Optimization》前 3–4 章
- [ ] 必掌握:梯度下降 · SGD/动量/Adam 思想 · 凸性 · 学习率
- [ ] 🎯 手写 SGD 训练阶段 2 的小网络,观察损失下降

## 🟢 阶段 5:经典机器学习(应用)· ~6–8 周

数学第一次变现。倒查式:每个算法回看它踩的线代/概率。

- [ ] 主线:《机器学习》(Book7)+《数据有道》(图/谱聚类/PageRank)
- [ ] 必做:从零实现 线性回归 · 逻辑回归 · PCA · k 均值 · 一个简单 SVM
- [ ] 🎯 不用 sklearn,纯 NumPy 跑通上面 5 个算法

## 🚀 阶段 6:深度学习(系列之外)· 持续

数学地基打牢后,进入真正的深度学习。

- [ ] 框架:PyTorch(边学边写)
- [ ] 理论:Goodfellow《Deep Learning》(前几章是数学总复习)
- [ ] 课程:吴恩达 DL Specialization(温和)/ Stanford CS231n(硬核)/ fast.ai(快速上手)
- [ ] 🎯 手写 MLP 训练 MNIST → PyTorch 复现 → 读懂一篇经典论文的数学

## 会拖慢你的 5 个坑

- ✕ 想把数学全学完再碰 ML —— 永远学不完,倒查式才快。
- ✕ 死磕纯证明 —— DL 要会用 + 有直觉,不是数学系的严谨。
- ✕ 跳过矩阵求导 / backprop —— DL 命门,省不得。
- ✕ 只看不动手 —— 每阶段必须有"从零手写"里程碑。
- ✕ 收集资料代替学习 —— 书已够多,按这张图走别再找新书。
